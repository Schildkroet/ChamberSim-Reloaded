# Project database (`data/`)

Long form: `data/README.md` (format, units per column), `docs/CONTRIBUTING.md` (procedures), `docs/DATA_SOURCES.md`.

## What may go in

- Own measurements, or values published by a manufacturer, C.I.P. or SAAMI. The source goes in `origin` or `descr`.
- **Never** anything from Gordon's Reloading Tool's database or another program's database, including fitted powder
  models (Ba, a0, z1, z2). If you cannot name where a value comes from, it does not go in.
- `data/` is CC BY-SA 4.0, separate from the code licence.
- Pistol and revolver powders are included too, even when their fit errors are larger; the `descr` says so.

## Files

- `data/calibers/<name>.json` one record each; `data/projectiles/<maker>.json` and `data/propellants/<maker>.json`
  one array per manufacturer. Merge single exported records with
  `python3 scripts/data/recordfiles.py data/projectiles` (or `data/propellants`); Python scripts read and write record
  files only through `scripts/data/recordfiles.py`.
- Units are the database columns' units, not display units: projectile mass in **grain**, case capacity `V` in
  **grain H₂O**, lengths mm, pressures bar, densities kg/m³. No `id`, no `geloescht`.
- `data/physical/propellants.json` and `calibers.json` are generated by `analysis/fit_physical_powders.py` and
  `analysis/fit_caliber_scales.py`: don't hand-edit them (see the csr-solver-accuracy skill).
- `data/measurements/<maker>-<name>-<lot>/` holds the load files a fit used, so others can repeat it.
- The records are compiled in as `:/data`: rebuild to see a change in the app.

## Checks

```bash
build/debug/csr_datacheck data          # = ctest projectdata, also run by CI
```

It checks JSON, known columns, numbers, names, plausible model values and duplicate names. A new record should also be
tried in a load (`csr_sim` or the app) and give sane pressure and velocity.

## Powder fits

```bash
build/release/csr_fitpowder [--model original|physical] --out maker-name-lot.json a.csrload b.csrload ...
build/release/csr_fitdata samples.csv --params Ba [--use-pressure] [--holdout "308 Win."] --out record.json
```

A fit needs 2 calibers x 2 bullet weights x 2 charges x ~5 shots (Measurements tab), differences under ~2 % per charge.
Qex, k, pc, pcd must come from the maker or a measurement, not from the fit. The published-load extractors in
`scripts/data/loaddata/` write sample CSVs that stay local (copyrighted tables): commit the scripts, not their output.
